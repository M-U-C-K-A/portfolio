Translating a site boils down to more than replacing "Bonjour" with "Hello". It is an architectural challenge that impacts routing, SEO, performance, and above all the developer experience.

In 2026, with the Next.js App Router, internationalization (i18n) has become more structured, but requires rigorous configuration to remain performant.

---

## 1. Routing: Why is `/fr` indispensable?

There are several ways to handle language (cookies, local storage, headers). However, for SEO, URL structure is the only viable method.

* **Sub-paths (Recommended):** `mysite.com/fr` or `mysite.com/en`.
* **Domains:** `mysite.fr` or `mysite.com`.

Using sub-paths allows search engines to index each version of your page independently. Next.js facilitates this thanks to **Middleware**, which intercepts the request, detects the browser language, and redirects the user to the correct prefix if necessary.

---

## 2. Middleware: The Conductor (Concrete Example)

This is where the magic happens. The middleware intercepts each request to direct the user to the correct language.

```typescript
import createMiddleware from 'next-intl/middleware';

export default createMiddleware({
  // A list of all supported locales
  locales: ['en', 'fr'],

  // If no locale matches, use this one
  defaultLocale: 'fr',

  // Redirects / to /fr
  localePrefix: 'always'
});

export const config = {
  // Match only internationalized pages
  matcher: ['/', '/(fr|en)/:path*']
};
```

This simple configuration automatically handles browser language detection and 307 redirects.

## 2. Dictionary Organization: Typing First

The classic mistake is using simple JSON objects without protection. As a full-stack developer, you want TypeScript to yell at you if you forget a translation key in a language.

### Recommended Structure
```text
messages/
  en.json
  fr.json

```

### Strict Translation Typing

By using libraries like `next-intl` or `i18next`, you can link your JSON files to your types:

```typescript
// Example of a typed component
import { useTranslations } from 'next-intl';

export function LoginButton() {
  const t = useTranslations('Auth');

  // TypeScript will validate that 'login_label' exists in fr.json and en.json
  return <button>{t('login_label')}</button>;
}

```

## 3. SEO and Accessibility: The Forgotten Heroes of i18n

Translating the interface is good, but you mustn't forget technical metadata.

1. **The `lang` attribute:** Your `<html lang="fr">` tag must change dynamically. This is crucial for screen readers (Accessibility) so they use the correct speech synthesis.
2. **`hreflang` tags:** They indicate to Google the relationship between your pages. If I am on the "À propos" page in French, the `hreflang` tag must point to the "About" version in English.

## 4. Dates, Numbers, and Currencies: The Intl API

Never translate dates or currencies manually. The browser and Node.js have an ultra-powerful native API: `Intl`.

```javascript
const price = 1250.50;
new Intl.NumberFormat('fr-FR', { style: 'currency', currency: 'EUR' }).format(price);
// Result: 1 250,50 €

new Intl.NumberFormat('en-US', { style: 'currency', currency: 'USD' }).format(price);
// Result: $1,250.50

```

## 3. International SEO: The Devil is in the Details

Having a `/fr` and an `/en` is not enough. Google must understand the link between them.

### Hreflang Tags & Canonicals
`next-sitemap` or `next-seo` don't always handle this perfectly.
Make sure your `<head>` contains:
```html
<link rel="alternate" hreflang="en" href="https://site.com/en/blog" />
<link rel="alternate" hreflang="fr" href="https://site.com/fr/blog" />
<link rel="alternate" hreflang="x-default" href="https://site.com/en/blog" />
```
Without the `x-default`, Google might ignore your pages for users who speak neither FR nor EN.

### Localized Images
This is often forgotten: show a screenshot of the EN interface for English speakers, and FR for French speakers.
```tsx
const screenshot = locale === 'fr' ? '/img/app-fr.png' : '/img/app-en.png';
<Image src={screenshot} alt={t('screenshot_alt')} />
```
It's this kind of detail that increases your conversion rate by 15%.
