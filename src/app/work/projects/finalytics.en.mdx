## Overview

Finalytics was born from a simple observation: creating complete financial reports is a **slow, manual, and fragile** process. Between data extraction, calculations, layout standardization, and verifications, each delivery can take hours — or even days.

The project's goal is to **centralize data, automate processing** and generate professional reports in a reliable and reproducible manner. Finalytics thus reduces repetitive work to allow users to focus on analysis and decision-making, not formatting.

---

## Key Features

- **Import of standardized or heterogeneous data**
  Finalytics analyzes and normalizes files (accounting exports, balance sheets, journals, Excel sheets...) to produce a structured base.

- **Automatic report generation**
  A generation engine transforms this data into reports with **consistent layouts**, charts, comparative tables, and summaries.

- **Adaptable templates**
  Companies can adapt the tone, visual style, and structure according to their internal uses.

- **Version tracking & audit trail**
  Each report is documented, timestamped, and reproducible.

- **Performance & accessibility orientation**
  Interface designed to be readable, fast, without visual overload.

---

## Technologies Used

- **Next.js + React** for the application structure and UI
- **TypeScript** for robustness and maintainability
- **Tailwind + Atomic Design** for a clear and consistent visual hierarchy
- **Docker** to guarantee a reproducible environment
- **GitHub Actions** for continuous deployments

---

## Design & Front-End Approach

The interface is built using an **atomic design** approach, allowing:

- interface consistency across all pages
- easy evolution (adding new views, tables, charts...)
- **accessible** components (keyboard, contrasts, semantic structure)

The goal was to **minimize visual noise**: let the data breathe, remove unnecessary decorative elements, and guide attention to key indicators.

---

## Challenges and Learnings

- **Data source normalization**: financial formats are never really standard.
- **Performance**: generating heavy reports → pipeline optimization + pre-calculations.
- **UX for non-technical profiles**: simplifying the interface without hiding calculation complexity.

This project reinforced the idea that **simplifying is not removing**, but **reducing the interface to what really matters**.

---

## Outcome

Finalytics is currently in **continuous development**, with user feedback integrated as it comes.

Pilot users have observed:

- **Up to 70% time saved** on report preparation
- **Fewer human errors**
- **More consistency** between deliverables

The project established a **clean, structured, and sustainable front-end workflow** around atomic design, clean code, and accessibility.
