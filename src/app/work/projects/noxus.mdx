## Overview

Noxus casse la linéarité classique des manuels scolaires. L'application part du principe qu'une lacune en mathématiques est souvent un problème de **dépendance manquante** : on ne peut pas comprendre les puissances sans maîtriser la multiplication.

L'interface est volontairement **sobre et professionnelle**, inspirée d'outils de productivité comme Obsidian, pour mettre l'utilisateur dans une posture d'apprentissage sérieuse, quel que soit son âge.

Le projet est né d'un constat simple : les applications éducatives existantes traitent les mathématiques de manière linéaire, comme si chaque chapitre était indépendant. Or, les mathématiques sont par essence **interconnectées**. Comprendre les dérivées requiert de maîtriser les limites, qui elles-mêmes dépendent de la notion de fonction, etc.

---

## Le Problème Résolu

### Les Limites de l'Apprentissage Traditionnel

L'enseignement traditionnel des mathématiques souffre de plusieurs problèmes fondamentaux :

1. **La linéarité forcée** : Les programmes scolaires imposent un ordre rigide qui ne correspond pas toujours aux besoins individuels de chaque élève.

2. **L'accumulation de lacunes** : Quand un concept n'est pas compris, l'élève passe au suivant sans avoir consolidé les bases. Ces lacunes s'accumulent et deviennent des murs insurmontables.

3. **L'absence de vision globale** : L'élève ne voit jamais la "big picture" — comment les fractions se connectent aux pourcentages, comment l'algèbre prépare au calcul différentiel.

4. **La démotivation** : Sans comprendre le "pourquoi" de ce qu'on apprend, la motivation s'effrite rapidement.

### La Solution Noxus

Noxus répond à ces problèmes en proposant une **cartographie complète du savoir mathématique**. Chaque concept est un noeud, chaque pré-requis est un lien. L'utilisateur navigue librement dans ce graphe, explorant les connexions et comblant ses lacunes de manière ciblée.

## Fonctionnalités Clés

### 🕸️ Le Knowledge Graph

Le cœur de l'application est un système de **Noeuds et de Graphes**. Cette approche révolutionnaire permet de visualiser l'ensemble du curriculum mathématique comme un réseau interconnecté de concepts.

- Chaque notion est un noeud avec son propre contenu pédagogique.
- Les liens représentent les pré-requis et les débouchés.
- L'utilisateur visualise son chemin de progression et peut "remonter la source" d'une incompréhension.
- Navigation intuitive par zoom et déplacement dans le graphe.
- Filtrage par niveau (Primaire, Collège, Lycée, Supérieur).
- Recherche instantanée dans l'ensemble du graphe.

Le graphe contient actuellement **plus de 400 noeuds** couvrant l'intégralité du programme français, du CP jusqu'au niveau universitaire (Licence).

### 📚 Modules Riches & Hybrides

Les cours ne sont pas de simples textes. Le moteur de rendu supporte une variété de formats pour rendre l'apprentissage le plus efficace possible :

- **Markdown & LaTeX** : Pour des formules mathématiques au rendu impeccable.
- **Média Intégrés** : Vidéos, GIFs explicatifs, images interactives.
- **Tableaux & Références** : Pour structurer la donnée complexe.
- **Exercices interactifs** : QCM, problèmes à résoudre, et auto-évaluation.
- **Exemples commentés** : Des solutions détaillées pas à pas.
- **Liens croisés** : Références vers les concepts liés directement cliquables.

Chaque module est structuré de manière progressive, allant des concepts fondamentaux vers les applications plus avancées. La structure type d'un module comprend :

1. **Introduction** : Contexte et motivation du concept.
2. **Définitions** : Les notions clés présentées formellement.
3. **Explications** : Vulgarisation et intuitions.
4. **Exemples** : Applications concrètes.
5. **Exercices** : De difficulté croissante.
6. **Pour aller plus loin** : Liens vers les concepts avancés.

### 🎯 Adaptabilité du Contenu

Si l'interface principale reste unifiée et élégante (gestion fine des thèmes Dark/Light, contrastes), le **contenu pédagogique** s'adapte à la cible.

- Un module "Addition" pour le CP utilisera des emojis 🍎 et des exemples ludiques.
- Un module "Statistiques Inférentielles" pour la fac restera académique.
- Les explications s'adaptent au niveau de l'apprenant.
- Le vocabulaire évolue avec la complexité des sujets.
- Les exercices sont calibrés pour le niveau visé.

Cette adaptabilité permet à Noxus de servir aussi bien un enfant de 7 ans qu'un étudiant en prépa. L'interface reste la même, seul le contenu change.

### 🔒 Privacy by Design

La protection des données est une priorité absolue pour Noxus :

- **Aucune collecte de données personnelles** : Pas de tracking, pas de publicité.
- **Stockage local** : Toutes les données restent sur l'appareil de l'utilisateur.

Cette approche "privacy-first" est particulièrement importante pour une application éducative destinée aux enfants.

## Philosophie Pédagogique

### Apprendre en Comprenant, Pas en Mémorisant

Noxus repose sur une conviction forte : les mathématiques ne s'apprennent pas par cœur, elles se **comprennent**. Chaque lacune est une porte vers un pré-requis à consolider.

L'approche par graphe permet de :

1. **Identifier les lacunes** : Plutôt que de buter sur un concept, l'utilisateur peut explorer ses fondations.
2. **Construire une compréhension solide** : En maîtrisant chaque noeud avant de passer au suivant.
3. **Personnaliser le parcours** : Chacun avance à son rythme, selon ses forces et faiblesses.
4. **Visualiser sa progression** : Le graphe devient une carte de son savoir acquis.
5. **Faire des connexions** : Voir comment les concepts s'articulent entre eux.

### Du CP à l'Université

Le contenu couvre l'intégralité du curriculum mathématique français :

- **Primaire (CP-CM2)** : Numération, opérations, géométrie de base, mesures, problèmes simples.
- **Collège (6ème-3ème)** : Algèbre, fractions, fonctions, statistiques descriptives, géométrie plane.
- **Lycée (2nde-Terminale)** : Analyse, suites, probabilités, géométrie vectorielle, trigonométrie.
- **Supérieur (Licence)** : Analyse réelle, algèbre linéaire, statistiques inférentielles, calcul différentiel.

Chaque niveau est représenté par une couleur distincte dans le graphe, permettant une navigation visuelle intuitive.

### L'Autonomie comme Objectif

L'objectif ultime de Noxus n'est pas que l'utilisateur reste dépendant de l'application, mais qu'il développe les compétences pour **apprendre de manière autonome**. L'app fournit :

- Des méthodes de raisonnement réutilisables.
- L'habitude de chercher les fondations quand quelque chose n'est pas compris.
- La capacité à faire des connexions entre concepts.

## Défis Techniques

### Rendu LaTeX sur Mobile

L'un des plus grands défis a été d'obtenir un rendu LaTeX fluide et performant sur mobile. Les solutions existantes étaient soit trop lentes, soit incomplètes.

**Approches testées et abandonnées :**
- **WebView** : Trop lent, problèmes de communication.
- **react-native-katex** : Rendu inconsistant, dépendance lourde.
- **MathJax** : Overhead JavaScript trop important.

**Notre solution custom** utilise un parser optimisé qui :
- Pré-compile les expressions LaTeX au build time quand possible.
- Utilise le cache pour les expressions récurrentes (LRU cache de 500 entrées).
- Optimise le rendu SVG pour les formules complexes.
- Supporte le rendu inline et block.
- Gère les erreurs de syntaxe gracieusement.

Le résultat : un rendu **60fps** même sur des pages avec 50+ formules.

### Performance du Graphe

Afficher un graphe de plusieurs centaines de noeuds de manière fluide a nécessité des optimisations poussées :

- **Culling spatial** : Seuls les noeuds visibles sont rendus.
- **LOD dynamique** : Le niveau de détail s'adapte au zoom.
- **Quadtree** : Structure de données pour les requêtes spatiales efficaces.
- **Animation native** : Transitions gérées sur le thread UI natif.
- **Mise en page incrémentale** : Le layout du graphe est calculé progressivement.

Ces optimisations permettent une navigation fluide même avec 400+ noeuds et 800+ liens.

### Synchronisation Offline-First

Noxus fonctionne parfaitement hors-ligne, ce qui a nécessité une architecture robuste :

- **SQLite local** : Toute la progression est stockée localement.
- **Sync queue** : Les modifications sont mises en file d'attente pour synchronisation.
- **Conflict resolution** : Gestion des conflits en cas de modifications simultanées.
- **Delta sync** : Seules les différences sont synchronisées.

## Architecture du Contenu

### Structure d'un Module

Chaque module de Noxus suit une structure JSON standardisée :

```json
{
  "id": "derivatives-intro",
  "title": "Introduction aux Dérivées",
  "level": "lycee",
  "xp": 50,
  "prerequisites": ["limits-intuition", "functions-continuity"],
  "unlocks": ["derivatives-rules", "derivatives-applications"],
  "content": {
    "sections": [...],
    "exercises": [...],
    "references": [...]
  }
}
```

### Graphe de Dépendances

Le graphe est modélisé comme un **DAG (Directed Acyclic Graph)** :
- Chaque noeud a des pré-requis et des débouchés.
- Aucun cycle n'est autorisé (impossible de revenir à un pré-requis).
- Des algorithmes de validation garantissent l'intégrité du graphe.
