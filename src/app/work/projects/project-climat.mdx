## Overview

Project Climat est un projet éditorial né de l’envie de **rendre les enjeux climatiques compréhensibles**, sans sensationnalisme ni surcharge d’informations.

Plutôt que d’inonder l’utilisateur de chiffres ou d’alertes anxiogènes, l’objectif était de **créer un espace calme**, pensé pour la lecture longue, la réflexion et la nuance.

L’approche s’est concentrée sur trois axes :

- **Lisibilité avant tout**
- **Navigation simple et non agressive**
- **Tonalité pédagogique, pas militante**

---

## Key Features

- **Articles structurés et narratifs**
- **Typographie optimisée pour la lecture longue**
- **Hiérarchie d’informations claire**
- **Mode sombre lisible et accessible**
- **Système de tags pour explorer les sujets**

---

## Design Approach

L’interface est volontairement **silencieuse** :  
pas d’animations inutiles, pas de surcharge graphique.

Principes utilisés :

- Espaces généreux
- Grille stable
- Couleurs neutres
- Accent minimal
- Focus sur la **respiration visuelle**

Le but est de **rester au service de la réflexion**, pas de distraire.

---

## Technologies Used

- Next.js + React
- TypeScript
- TailwindCSS (approche Atomic Design)
- Markdown/MDX pour l’édition des articles

---

## Outcome

Project Climat sert aujourd’hui de base solide pour :

- publier des articles,
- organiser la connaissance,
- structurer des analyses et synthèses.

Il est conçu comme un **outil d’apprentissage** autant qu’un média.

Ce projet démontre l’importance de **concevoir des interfaces lentes**, pensées pour la lecture, l’attention et la nuance.
